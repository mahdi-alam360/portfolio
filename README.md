# Mahdi Alam — Portfolio

Software developer portfolio built with HTML, CSS, and JavaScript.

## Files

- `index.html`: profile, project breakdowns, education, and contact links
- `style.css`: responsive design and reduced-motion support
- `script.js`: email copying and section navigation
- `icon.svg`: favicon
- `mahdi-alam-resume.pdf`: downloadable resume

## Run locally

Serve the repository root with any static HTTP server, or open `index.html` in a browser. No build or package installation is required.

## Hosting

Prepared for static hosting on Vercel. The initial deployment uses Vercel's direct file upload workflow. Git pushes do not trigger deployment until this repository is connected in Vercel.

## Project links

The project repositories linked from the site currently contain documentation; their original source code has not been added.
